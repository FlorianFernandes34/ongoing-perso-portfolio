# Portfolio — Florian Fernandes

Portfolio personnel présentant mon profil, mon parcours, mes compétences et mes projets en développement.

## Aperçu

Ce site a été conçu comme une vitrine claire et minimaliste de mon travail et de mon évolution en tant que développeur.
Il présente notamment :

* mon profil et mon parcours
* mes compétences techniques
* mes projets
* mes expériences professionnelles
* ma veille technologique

## Stack technique

* **PHP**
* **CodeIgniter 4**
* **Tailwind CSS**
* **HTML / CSS**
* **JavaScript**

## Structure

Le projet suit l’architecture standard de CodeIgniter 4 :

```
app/
public/
writable/
vendor/
```
